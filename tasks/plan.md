# Implementation Plan: UI инженера (вьюер + таблица замечаний)

## Overview

Сделать интерфейс проверки ПД нативно понятным без инструкции: большие листы и мелкие элементы читаются, масштаб управляется как в CAD/PDF-просмотрщике, замечания разбираются на месте без россыпи вкладок. Деплой на прод — только после локальной проверки каждого этапа.

Локальный гейт после этапа: `npx tsc --noEmit`, `npm run lint`, `npm run test:content-sync`, `npm run test:reviews`, `npm run test:uploads`. Живая проверка: `npm run dev` → `PTO_BASE_URL=http://localhost:3000` + QA-комплект (`seed-qa-kit-mixed.mjs`) + `verify-kit-highlight.mjs` (регресс подсветки 8/8).

## Architecture Decisions

- Общий хук `usePageViewport` — один источник pan/zoom/fit для PDF и CAD. Иначе зум, мини-карта и жесты разъедутся в двух файлах.
- Общая панель `ViewerToolbar` — процент, fit, листы, весь экран. CAD добавляет свои переключатели справа.
- Предпочтения (плотность, колесо CAD, крупные подписи, миниатюры, подсказка) — `localStorage` через `src/lib/viewer-prefs.ts`.
- Карта клавиш — один объект `src/lib/keymap.ts`; UI и `?`-диалог читают его. Инструкция больше не живёт отдельно от кода.
- Переход из таблицы: обычный клик — та же вкладка; Ctrl/⌘+клик и средняя кнопка — новая (нативное поведение ссылки).
- Цвет: синий = активное действие; красный/янтарь/зелёный = состояния; остальное нейтральное.
- Колесо: PDF — прокрутка, Ctrl — зум; CAD — зум, Ctrl — прокрутка (как TrueView). Переключатель в prefs.
- Стрелки ←/→ — пан; листы — J/K, PageUp/PageDown, пробел.
- Плотность по умолчанию «обычная» (контрол 28 px, 12 px текст). «Компактная» = текущая мелкая.

## Risks and Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| Хук сломает кэш вида / подсветку | High | Этап 0 без новых жестов; регресс highlight первым |
| ResizeObserver сбрасывает ручной зум | Med | Не менять текущий контракт (fit при ресайзе панели) |
| Рейка + таблица + клавиши конфликтуют | Med | Фокус: вьюпорт / рейка / таблица; typing в input не перехватываем |
| Плотность ломает существующие тесты Playwright | Med | data-атрибуты и селекторы не трогать; менять только классы |
| CAD wheel=zoom удивит привыкших к PDF | Low | Prefs + подсказка первые 3 сессии |
