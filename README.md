# PTO — проверка чертежей

Черновик интерфейса: загрузка PDF, чертёж слева, Markdown справа.

## Локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3001 (или 3000).

Тестовые чертежи лежат в `samples/`.

## Команде

Репозиторий приватный. Попросите доступ у владельца. Прод-ссылка появится после деплоя.
