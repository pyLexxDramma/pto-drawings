# Схема: пины замечаний на чертеже ↔ полоса справа

Как инженер читает экран и как слои связаны.

## Картинка целиком

```
  ┌─────────────────────────────── чертёж ───────────────────────────────┐
  │                                                                      │
  │     [13]  ← пин (номер замечания, цвет = важность)                   │
  │       ╲                                                              │
  │        ╲  рамка места (подсветка активного замечания)                │
  │         ▼                                                            │
  │      ┌──────┐                                                        │
  │      │+0.150│  ← цитата / зона на плане                              │
  │      └──────┘                                                        │
  │                                                                      │
  └──────────────────────────────────┬───────────────────────────────────┘
                                     │ клик по пину / строке
                                     ▼
  ┌────────────────────── замечания по листу ────────────────────────────┐
  │  № 13 · высокий · «отметка +0.150 …»     [№1] [№2] [№3]              │
  │   ▲ номер = цифра на пине                 ▲ места того же замечания  │
  │   ▲ цвет строки / пина = важность         │ (прыжок по экземплярам)  │
  └──────────────────────────────────────────────────────────────────────┘
```

## Что есть на чертеже

| Символ | Как называть | Значение |
|--------|--------------|----------|
| Цветной квадрат с цифрой | **пин** / маркер замечания | Номер замечания на этом листе |
| Цвет пина | важность | красный = высокий, янтарный = средний, синий = низкий |
| Рамка/заливка вокруг места | место замечания | Куда сейчас смотрит активное замечание |
| Полупрозрачный фон пина | — | Чертёж читается под маркером |

Пин ставится **чуть выше и левее** зоны места, чтобы не закрывать подпись на плане.

## Что есть справа

| Элемент | Как называть | Значение |
|---------|--------------|----------|
| Строка «№ N · …» | **замечание № N** | Одна находка / одно расхождение |
| Цвет рамки строки | важность | Та же шкала, что у пина |
| Чипы **№1 · №2 · №3** | места замечания | Не другие замечания, а точки одного и того же |

## Синхронизация

```
пин «13»  ←→  строка «№ 13»
цвет пина ←→  важность строки
клик пина →   активная строка + подсветка места
чип №2    →   второе место того же замечания №13
```

Без координат (`rect`) пин на плане не рисуется — строка справа всё равно есть.
